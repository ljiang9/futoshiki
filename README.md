# futoshiki 不等式数独

终端里的不等式数独小玩具：生成 4×4 / 5×5 谜题 + 回溯求解器。纯标准库，零依赖。

## 规则

- n×n 棋盘，每行每列恰好填入 1..n（拉丁方）
- 相邻格之间的不等号必须成立：`<` `>` 横向，`^` `v` 纵向，**尖端永远指向较小的一方**
- `.` 为空格

## 用法

```bash
python -m futoshiki                 # 生成一道 5x5
python -m futoshiki --seed 42       # 固定种子，可复现
python -m futoshiki --size 4        # 4x4
python -m futoshiki --solution      # 同时打印答案
python -m futoshiki --count         # 统计解的个数（上限 2，检查唯一性）
python -m futoshiki --save 题.txt   # 保存谜题
python -m futoshiki --load 题.txt --solve   # 求解文件中的谜题
```

示例（`--seed 42`）：

```
2 < 4 > . < .   .
 v     ^     v           ^
.   .   .   .   3
       v     v
.   . > 3   2   1
       ^     v
. > .   . > 1 < .

.   3 < .   .   .
```

## 设计取舍

- **生成器**：先造一个随机拉丁方做答案，再从答案导出不等号（只放与答案一致的方向），最后随机挖掉一部分格子做给定数。生成器**保证可解**（答案本身就是解），但**不保证唯一解**。
- **求解器**：朴素回溯 + 一致性剪枝（行列互异 + 不等号）。5×5 规模下毫秒级，无需复杂传播。
- 文件格式：首行 n，随后 n 行棋盘（0=空），n 行横向不等号（`.`=无），n-1 行纵向不等号。

## 真实验证记录

- `py_compile`：`futoshiki.py` / `__main__.py` 通过
- 手工 4×4 谜题（答案预先验算为拉丁方）：求解器找到**唯一解**，与预期答案逐格一致
- 随机生成：5×5 和 4×4 各 20 个种子，**40/40 可解**，每个解都通过 `check_solution`（拉丁方 + 全部不等号 + 给定数一致）
- 矛盾谜题（同行两个 1）：正确返回 0 解
- `--save` → `--load` → `--solve` 往返正常

## 已知局限

- 只做 4×4 / 5×5 小棋盘；回溯求解在大棋盘上会明显变慢
- 生成的谜题**不保证唯一解**，`--count` 会如实报告
- 难度未经分级，就是"能解"级别的小玩具
- 需要 Python 3.10+；中文界面
